Meniscus Annotator - installed synthetic software checks

These tools generate geometric phantoms, never locate participant MRI, and use
only the module and dependencies installed with this application. A source
checkout, system Python, terminal or runtime download is not required.

Maintainer tools are inside the installation folder, not in the reader's
Start menu. Open that folder in File Explorer and run the named executable:
  MeniscusAnnotatorExamples.exe - creates two complete flat-layout correction cases in a new
  OS-resolved local test folder, then shows its location. In the normal reader,
  choose Open dataset and that synthetic package for manual interface practice.
  Each has an explicit draft correction job and two colored geometric patches
  on the middle acquired slice. The actor is an unverified practice user, never
  a research reader. The shapes are not anatomical teaching examples.

  MeniscusAnnotatorDrawChecks.exe - tests the focused Draw/Erase workflow using
  eight known grids: left/right knees, both physical slice directions, and
  regular/oblique acquisition planes. It checks native contour filling,
  unfinished-contour guards, exact Undo/Redo, review, saving and export.

  MeniscusAnnotatorDrawResumeCheck.exe - after successful Draw checks, reopens
  the same managed synthetic work in a separate process.

  MeniscusAnnotatorDrawLayoutChecks.exe - checks layout using the same managed
  fixture. Maintainer CI can set QT_SCALE_FACTOR and MENISCUS_DRAW_SCALE_NAME
  before launch. Such simulation is not physical Windows display-DPI testing.

  MeniscusAnnotatorRegionsChecks.exe - exercises the optional regional draft
  workflow on known synthetic grids, with separate six-region state and whole
  medial/lateral labels preserved. Expert protocol remains pending; technical
  checks do not approve regions or accept any regional training voxels.

  MeniscusAnnotatorRegionsResumeCheck.exe - after successful regional checks,
  reopens that same managed synthetic work in a separate process.

  MeniscusAnnotatorCorrectionChecks.exe - uses a separate automated fixture through Open dataset,
  exact starting-mask loading, native-plane paint/erase/undo/redo, save/reopen,
  practice approval, actual Export/Cancel dialog buttons and ZIP verification.
  Qt/VTK events are injected. The native destination picker is redirected into
  the isolated test output and still needs a human acceptance check.

  MeniscusAnnotatorCorrectionResumeCheck.exe - opens a fresh process after successful correction
  checks, restoring both cases, edited voxels, review state and acquired slice.

  MeniscusAnnotatorChecks.exe - exercises the installed module's native
  acquired-plane strokes, review, save/reopen, practice approval and export. The
  suite closes its own test window after checking close/save recovery. A result
  dialog reports the result and offers the generated report/screenshot folder.

  MeniscusAnnotatorResumeCheck.exe - start this only after a successful workflow check.
  It opens a fresh process and verifies the previous synthetic case, slice,
  notes and native masks. The test profile is separate from the ordinary reader profile.

Every invocation uses a fresh folder under the operating system's local app-data
location / Meniscus Annotator synthetic tests. Input examples, work, exports and
reports stay there, outside the installation and ordinary annotation work.
Reports are installed-tests.json, correction-workflow.json (correction routes),
draw-workflow.json/draw-resume.json/draw-layout-SCALE.json (Draw routes), and
regions-workflow.json/regions-resume.json (regional routes), and
slicer-workflow.json (general workflow/resume). Reports include the installed
source commit and source fingerprint; the 0.1.0 label alone is not build identity.
Uncertainty and practice results remain explicitly marked. Technical acceptance
is not anatomical correctness, independent review or training-loader acceptance.

If a maintainer is already using normal PowerShell, these equivalents need no
Python installation (set $install to the chosen installation folder):
  & (Join-Path $install 'MeniscusAnnotatorExamples.exe')
  & (Join-Path $install 'MeniscusAnnotatorChecks.exe')
  & (Join-Path $install 'MeniscusAnnotatorResumeCheck.exe')
  & (Join-Path $install 'MeniscusAnnotatorCorrectionChecks.exe')
  & (Join-Path $install 'MeniscusAnnotatorCorrectionResumeCheck.exe')
  & (Join-Path $install 'MeniscusAnnotatorDrawChecks.exe')
  & (Join-Path $install 'MeniscusAnnotatorDrawResumeCheck.exe')
  & (Join-Path $install 'MeniscusAnnotatorRegionsChecks.exe')
  & (Join-Path $install 'MeniscusAnnotatorRegionsResumeCheck.exe')

RunSyntheticChecks.ps1 is an optional convenience for maintainers. Do not bypass
institutional script restrictions; the native executables above are available.
Only use the regular reader for authorised real-data annotation.
