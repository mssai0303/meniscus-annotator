Meniscus Annotator user guide

Open your assigned MRI scans, correct the supplied meniscus masks, and return reviewed results. Follow the study protocol when deciding which tissue to include. This application and its 3D Slicer runtime are for research annotation, not clinical diagnosis or treatment.

  1. Install and open

    Extract the supplied ZIP folders first. Run the supplied 0.2.0 Windows x64 installer, then open Meniscus Annotator from the Start menu. Python and the pinned Slicer runtime are included.

    The installer is unsigned. If Windows shows Unknown publisher or SmartScreen, confirm the authorized source and the coordinator’s SHA256 checksum; ask institutional IT to verify or approve installation. Do not disable security protections. Slicer may show its research-use notice on first launch.

  2. Open your assignment

    Choose Dataset → Open dataset. Select the complete Meniscus_annotation_data folder containing README.txt, case_index.csv and Cases. Do not select an individual scan. Starting masks load only from the explicit correction assignment; they are unreviewed predictions. If blank annotation is offered when you expected masks, cancel and obtain the correction package.

    In Confirm reader identity, enter your name or study ID, check I confirm this is my reader identity, then Continue. On shared accounts, check the Last used name. Use the same spelling each time and never accept another reader’s assignment.

    Accept the proposed local application-data work folder, or choose another persistent local folder outside Dropbox and OneDrive. Each reader has separate work. Common synced paths are checked, but institutional synchronization cannot always be detected. Dataset → Reader and dataset shows the reader, assignment and exact path; Show saved work opens it. MRI inputs and starting masks stay unchanged.

  3. Inspect and correct

    Open a case and check its ID, visit, knee side and selected compartment. A new correction case opens on a useful slice containing the starting mask when available; saved work resumes at the last slice. Inspect the entire stack using the slider, wheel or Previous/Next. Anterior is presented toward the left using physical geometry. Next: toward medial/lateral, or an oblique-direction message, describes increasing slice number. Labels are never swapped automatically; investigate any medial/lateral advisory.

    MedialLateralUncertain area

    Draw opens by default. Click around the boundary, then right-click without dragging to close and fill. Use Erase for excess pixels, Paint for small additions and Undo/Redo for committed edits. Brush size appears only for brush tools. A compartment-transfer notice offers Undo if an edit moves tissue between labels.

    Unfinished points are not saved masks. Finish or discard before changing slices, targets or cases. On close, choose Finish contour, Discard contour or Keep drawing (default). Finish requires at least three valid points. Ctrl+wheel zooms; middle-drag pans. Draw reserves right-click for finishing.

    Show annotation reveals the underlying MRI. Image and annotation display provides Outline width (2 px by default), transparent fill, Window/level and Reset view. These settings do not change mask geometry. Cases and Tools collapse and reopen the panels. An empty starting-mask slice does not establish absent meniscus.

  4. Distinguish whole masks and draft regions

    Use Whole meniscus for the complete Medial or Lateral mask, including its body. In the annotation panel, Regions (draft) reveals AH (anterior horn), Body and PH (posterior horn). Body is one region inside a whole meniscus. Regional drawing stays inside its selected parent; Erase returns tissue to unassigned. Return to Whole meniscus to add tissue.

    The assessment heading names its compartment and region. Choose Unassessed, Present, Absent or Uncertain and record a region-level note. An absent region requires no artificial voxels. Boundary uncertain and Flag regional review remain separate. Changing assessment does not erase completed review marks; tissue edits require review again.

    The expert regional protocol is pending. Do not infer regions from image halves or slice order. Regional research approval is unavailable and regional training validity is zero everywhere. Whole-mask approval never approves regions.

  5. Review and save

    Mark reviewed and next records an explicit inspection, including empty slices. In Whole meniscus it reviews the whole-mask slice. In Regions it reviews the selected compartment on that slice; review both separately. Scrolling is not review.

    Case notes and slice flag contains one shared note for the case and a separate Flag this slice control. Regional assessment has a note for the named region and its separate review flag. Shortcuts stay inactive while entering text.

    Use Save draft before a break and wait for Saved. Saving preserves both tasks without approval. To resume, reopen and confirm the same reader, dataset and work folder. If Save failed appears, keep the app open, check local space and permissions, then retry. Unfinished contours and in-memory Undo history are not restored after restart.

  6. Approve the whole mask

    After every slice is reviewed, choose Go to approval. Resolve uncertainty and flags and confirm both compartment checks. In Whole meniscus, choose Approve practice case for a draft protocol, or Approve case under a released protocol. Read the confirmation. The named reader is both annotator and approver, not an independent second reader.

    Practice completion is ineligible for research/training. Explicit software-practice work is also excluded and has zero validity everywhere. Editing approved tissue starts a new draft; re-marking an unchanged reviewed slice does not remove approval.

  7. Export the intended versions

    Choose Dataset → Export results. Review each included or excluded case, checkpoint version and action/reason. For a draft protocol, practice export is selected and locked automatically. Selected cases must be eligible; unresolved review, uncertainty or flags need attention.

    When a newer unapproved draft exists, approve it first, explicitly choose Explicitly use the earlier approved versions listed below, or Exclude cases with newer unapproved work. The app does not silently send an older version. Choosing an earlier approval omits the newer edits.

    Choose Export and a destination. A checked ZIP is created in its Meniscus_annotation_results subfolder; Show exported file opens that folder. MRI images are not duplicated. The ZIP records the confirmed versions and exclusions. Return it through the coordinator’s authorized route and keep the local work until receipt is confirmed.

Update from 0.1.0: save and close the old app normally. Preserve the dataset, work folder and return ZIPs. Uninstall the old app through Windows Settings, install 0.2.0, then reopen the original dataset and confirm the same reader. If needed, choose Open existing work and select the folder containing dataset.json and cases. Do not manually rename or merge checkpoints.

For help, preserve your work and contact the coordinator. Keep diagnostics and real-image screenshots private. On a virtual desktop, confirm where files persist after logout. Do not change the annotation job or reader identity to work around a save or approval error.
