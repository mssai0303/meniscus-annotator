Meniscus Annotator user guide

Open your assigned MRI scans, correct the supplied meniscus outlines, and return your reviewed results. Follow the study annotation protocol when deciding which tissue to include.

Before you start
Use the software version and case folder supplied by your coordinator. The software and downloaded cases are designed for local work. Keep your saved work until the coordinator confirms receipt.

  1. Install and open

    Extract the supplied ZIP folders first. Run the supplied Windows installer, then open Meniscus Annotator from the Start menu. You do not need to install Python or download Slicer separately.

  2. Open your assignment

    Choose Dataset → Open dataset. Select Meniscus_annotation_data itself: the folder containing README.txt, case_index.csv, and Cases. Do not select the Cases subfolder or an individual scan.

    Enter your name or assigned reader ID when prompted. Use the same spelling each time. If an assignment already names a reader, confirm it only if it is yours. Choose the proposed local work folder, or another local folder outside Dropbox and OneDrive. Each reader keeps a separate work folder.

    The MRI inputs stay unchanged. Corrections are saved in the separate work folder. Use Dataset → Show saved work to find it.

  3. Inspect and correct

    Double-click a case. The header shows its ID, visit, knee side and save state. The annotation panel shows the selected compartment and tool. Expand Case details and approval for the reader and starting-mask mode. Use the slice slider or mouse wheel to inspect the full scan, with the outlines both visible and hidden.

    Cases and Tools collapse and reopen the side panels. Close Cases while drawing to give the MRI more space; the application remembers your panel preferences.

    MedialLateralUncertain area

    Draw opens by default. Select Medial or Lateral. Click around the boundary; right-click without dragging to close and fill on this acquired slice. Use Erase to remove excess pixels and Paint for small additions. Brush size appears only for those brush tools. Use Undo/Redo for committed edits. Ctrl+wheel zooms; middle-drag pans. Right-drag does not finish or zoom an unfinished Draw contour.

    Light yellow points and lines are an unfinished contour, not a committed mask. Finish it or choose Discard before changing slices, labels or cases, saving or closing. Discard defaults to Keep drawing. An empty starting-mask slice does not imply absent meniscus; inspect the full stack under the protocol. If the application offers blank annotation when you expected predictions, cancel and contact your coordinator.

  4. Assign regions in practice

    Correct the whole masks first. Choose Task → Regions, select Medial or Lateral, then choose Anterior horn (AH), Body or Posterior horn (PH). Draw, Erase and Paint work only inside the selected whole meniscus. Erasing an assignment returns its tissue to unassigned. Return to Whole meniscus to add or remove tissue.

    Existing masks start unassigned. Do not infer anatomical regions from image halves, slice order or screen position. In Regional assessment, record Not assessed, Present, Absent or Uncertain, with a note as needed. An absent region does not require artificial voxels. Use Boundary uncertain for separate regional uncertainty and the regional flag for attention. Show regions is in Image and annotation display.

    The regional anatomical protocol is pending. These controls support draft practice. Regional research approval is unavailable, and regional training validity is zero everywhere. Whole-meniscus approval does not approve regional assignments.

  5. Review every slice and save

    After checking a slice, choose Mark reviewed and next in the bottom strip, including slices with no meniscus. In Whole meniscus, this records whole-mask review. In Regions, it records regional review for the selected Medial or Lateral compartment on that slice; review both separately. Editing affected tissue requires review again.

    Expand Slice notes and flags for whole-mask notes. Use Regional assessment for regional notes and flags. Use Save draft before a break and wait for Saved in the header. It preserves both tasks without approving either. To continue later, choose Dataset → Resume work.

  6. Approve a completed whole mask

    Choose Task → Whole meniscus. When all slices are reviewed, resolve whole-mask uncertainty and flags. Expand Case details and approval, confirm both compartment checks, then choose Approve case there. Read the confirmation before accepting. A draft protocol records practice completion; it does not create an approved training annotation. This action never approves regions.

  7. Export and send back

    Choose Dataset → Export results. Select all approved cases or the selected case, then choose Export and a destination. For an assigned practice batch, enable the practice option.

    After the completion message, choose Show exported file. Send the resulting ZIP file through the return route your coordinator provided. It contains your corrections and review records; MRI images are not duplicated in the ZIP.

If something is wrong: preserve the work folder and contact your coordinator. Do not rename files inside the case folder, change the annotation setup, or begin again under another reader's name.

On a university virtual desktop, ask where files persist after logout. Return your exported ZIP before the desktop is reset.
