# Repository policy

Use local Git from the beginning with clear commits and version tags (v0.1.0, etc.).
Publish source only to the private GitHub repository explicitly supplied by the owner.
No destination has been supplied as of initial development; no upload is authorized yet.
Commit code, build configuration, dependency locks, synthetic tests and documentation.
Never commit MRI data, real participant identifiers, annotations, credentials, private
logs or temporary files. Synthetic images are generated by tests outside the repository.
Distribute built installers through private GitHub Releases, never as source commits.
The saved annotation metadata records the application version and runtime versions.
